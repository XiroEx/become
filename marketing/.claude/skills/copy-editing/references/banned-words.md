# Banned Words and Phrases

Every entry has a replacement, not only a prohibition. "Cut it" is a valid replacement and is listed
as `(delete)` where the sentence works better without anything.

## Tier 1: banned outright in all Become copy

| Banned | Why | Replacement |
|---|---|---|
| journey | The category's most exhausted word. Says nothing. | the plan, this week, day one, or (delete) |
| unlock your potential | Empty promise, and a promise we cannot make | name the mechanic |
| game-changer | Hype with no content | (delete) |
| revolutionary | Same, plus it invites scrutiny we do not need | (delete) |
| seamless / seamlessly | Describes our plumbing, not their day | (delete), or name what does not break |
| effortless / effortlessly | Implies training is not work. It is. | fast, one tap, one photo |
| 10x | Fabricated multiple | (delete) |
| crush it | Bro-hype | (delete) |
| no excuses | Shame framing. Directly against our position. | (delete) |
| beast mode | Same | (delete) |
| just | Minimizes the reader's effort, reads as condescension | (delete) |
| simply | Same | (delete) |
| grind / hustle / no days off | Shame and burnout framing | (delete) |
| transform / transformation | Promises an outcome we cannot promise | change, build, or name the mechanic |
| elevate | Filler verb | (delete) |
| supercharge / turbocharge | Filler verb | (delete) |
| cutting-edge / next-generation | Unfalsifiable | name the mechanic |
| synergy / holistic / ecosystem | Corporate abstraction | one app, one plan, one screen |

## Tier 2: abstractions to replace with a concrete noun

Not banned in every context, but each one is a slot where a real noun does more work.

| Abstraction | Replace with |
|---|---|
| your fitness journey | your week, your plan, day one |
| experience | the screen, the session, the log |
| insights | your volume, your streak, your macros |
| potential | (delete), or the specific next lift |
| solution | app, plan, program |
| platform | app |
| wellness | training, food, mind |
| results | what changed, your trend, the recap |
| lifestyle | week, routine, schedule |
| optimize | plan, adjust, set |
| leverage / utilize | use, or the real verb |
| empower / enable | (delete), then say what it does |
| personalized | set to your goal, built from your answers |
| comprehensive / complete | name the five hubs |
| powerful / advanced / smart | name the mechanic |
| intuitive / easy to use | show a capture instead |

## Tier 3: hedges, which are claims you did not want to make

| Hedge | Fix |
|---|---|
| can help you | make the smaller true claim, or cut |
| designed to | it either does it or it does not |
| aims to | same |
| may improve / could lead to | delete the claim entirely |
| helps support | delete. This is supplement-label language. |
| one of the best | delete |
| arguably | delete |
| we believe | delete in product voice; acceptable in Jon's voice |

## Tier 4: fabrications, which are constraint violations rather than style problems

If any of these appear in a draft, they go in the **Claims flagged for verification** bucket and out
of the copy. They are not editable into acceptability.

| Phrase pattern | Why it is out |
|---|---|
| trusted by thousands / join 10,000+ | We have no user count to publish |
| the #1 fitness app | Fabricated rank |
| rated 4.8 stars | No ratings exist. Become is a PWA, not a store app. |
| "It changed my life" (unattributed quote) | Fabricated testimonial |
| lose 10 lbs in 30 days | Promised result and timeline |
| clinically proven / doctor recommended | Medical claim |
| free for a limited time / early-bird pricing | Invents a future price |
| starting at $X / Pro plan / upgrade | No pricing exists |
| 7-day free trial | No trial exists. Nothing is gated today. |
| before and after | Framing that implies a guaranteed outcome |
| built for people who are tired of being out of shape | Body-shaming |

The only permitted price statement is about today: nothing is gated, no credit card. Never "free
forever," never "free for now," never anything implying a future charge.

## AI-slop tells

Structural patterns rather than words. Each is a rewrite signal.

| Tell | Example | Fix |
|---|---|---|
| Tricolon addiction | "faster, smarter, stronger" | Pick one. Make it concrete. |
| "not just X, but Y" | "not just an app, but a system" | State Y directly |
| "It's not about X, it's about Y" | "It's not about willpower, it's about systems" | Say the Y sentence alone |
| "In a world where..." | any | Delete to the first real sentence |
| Symmetrical clause pairs | "Train with purpose. Eat with intention." | Break the symmetry; one of them is filler |
| Adjective stacking | "a beautiful, intuitive, powerful dashboard" | Zero adjectives, one mechanic |
| Em dash as the only punctuation | "Become is different — it's complete — and it's free" | Periods |
| Rhetorical question opener | "Tired of app-hopping?" | State the observation instead |
| "Whether you're X or Y" | "Whether you're a beginner or advanced" | Pick the reader you are writing to |
| Closing summary paragraph | "In short, Become brings it all together." | Delete. The copy already said it. |
| Emoji as bullet points | 🔥 💪 ✅ in a product block | Delete. One emoji max, social only. |

## Em dash policy

Deliverable copy runs near zero em dashes. Replacements, in order of preference:

1. A period. Two short sentences read better at 390px.
2. A comma, when the clauses are genuinely joined.
3. A colon, when the second half is a list or a definition.
4. Parentheses, sparingly.

Two exceptions, and only two: frontmatter `description` fields in this skill library, which are
metadata and follow the catalog's formula, and direct quotations from a source, which are reproduced
as written.

## Words that are fine and get over-flagged

Do not remove these in the name of tightening. They are the product's own language.

`log`, `scan`, `plan`, `count`, `recap`, `generate`, `show`, `set`, `rep`, `phase`, `program`,
`streak`, `macros`, `plate`, `session`, `mood`, `volume`, `PR`, `The Becoming` (at most one mention),
`coach`, `magic link`, `home screen`.
